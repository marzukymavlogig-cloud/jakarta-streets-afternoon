JAKARTA — Streets of the Afternoon: an original realistic-3D open-world crime game set in golden-hour Jakarta. Mara Voss returns home to save her brother's bengkel, driving and fighting through a living city — Monas crowds, kaki lima vendors, Sudirman towers and kampung, solid buildings, a face on every character, Los Santos-style bustle, and a CJ-style arsenal. Built by an AI agent for make.fun's "Make GTA 6" bounty, $1,666 in USDC.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```

Node 22, standard library only — no dependencies, no build step. Or play it live at https://marzukymavlogig-cloud.github.io/jakarta-streets-afternoon/game/

## The game

- **Jakarta, Indonesia** — Monas with its plaza crowds, Jl. Sudirman / MH Thamrin, Wisma 46, Bundaran HI, TransJakarta buses, bajaj, angkot, warung tenda, and a kampung district; rupiah economy, Indonesian radio.
- **Afternoon, realistic** — 17:00 golden hour: warm low sun, long shadows, haze, ACES tone mapping, wet-road shine.
- **Crowds** — 64 pedestrians, 12 vendor stalls (bakso, sate, nasi goreng, es teh and more), 29 traffic vehicles, honking, neon signs, traffic lights.
- **Faces on everyone** — every character, NPCs included, has a face; smooth walk/run/drive/shoot animations with real blending.
- **Solid city** — 214 colliders: buildings, towers, kampung houses, stalls and the Monas base are solid for feet, cars, pedestrians and police, with bump feedback.
- **CJ-style arsenal** — pistol, SMG, shotgun and rifle (keys 1–4, R reload), muzzle flash, drive-by shooting from the car, ammo crates around the city.
- **Story** — 5 easy story jobs plus repeatable taxi and delivery gigs, wanted 0–5 stars with police cars and a helicopter at 3+, saves, day–night cycle and weather.

Controls: WASD move/drive, E enter/exit car, M start mission, F punch/shoot, 1–4 switch weapon, R reload, Esc pause.
