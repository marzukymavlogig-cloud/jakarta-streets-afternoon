JAKARTA — Streets of the Afternoon is an original realistic-3D open-world crime game set in Jakarta at golden hour, built for the make.fun GTA 6 bounty. Drive down Jl. Sudirman past Monas, Wisma 46 and Bundaran HI through Los Santos-style bustle — TransJakarta buses, angkot, bajaj, ojol riders, street vendors and crowds with real faces — with solid collision, a CJ-style arsenal (pistol, SMG, shotgun, rifle), 5 story jobs, Indonesian radio, and a rupiah economy.

## Run it

```sh
node serve.ts --port 8080
```

Then open http://localhost:8080 in your browser.
